# mcst-2027 — 문화체육관광부 2027년 예산 정부안

기획예산처 열린재정 「재정사업별 상세설명자료」(2027년 정부안)로 만든 캠페인 데이터입니다. `scripts/openfiscal_to_json.py`가 만듭니다.

- `budget.json`: 화면이 읽는 데이터. 대분류 5개, 분야(프로그램) 36개, 세부사업 409개. 단위 백만원. 세부사업마다 열린재정 사업 ID(`id`, 22자리)와 설명자료 내려받기 주소(`url`)가 있습니다.
- `descriptions.json`: 출처·대분류·분야 설명. 대분류 설명과 `crosscheck`는 사람이 고치고, 분야 설명은 스크립트가 세부사업 이름으로 만듭니다.
- `excluded.json`: 뺀 내부거래·보전지출 22건(프로그램 8000·9000번대: 회계·기금 간 전출, 여유자금 예치, 공공자금관리기금 예탁·상환).

## 기준
- 분류와 2027년 정부안 금액: 열린재정 세부사업 목록(문화체육관광부 428건 중 내부거래 22건을 뺀 406건 + 미래대응기금 「(문체부)」 3건).
- 2025년 결산·2026년 본예산(기금은 당초계획): 사업별 설명자료의 예산 총괄표.
- 합계 9조 6,345억 원 = 문화체육관광부 총지출 8조 6,502억 원 + 미래대응기금 편성 9,843억 원. 문화체육관광부 발표 총액, 국회 문화체육관광위원회 검토보고서의 총지출과 같습니다.
- 분야 = 문화체육관광부 프로그램. 대분류 = 프로그램 코드 범위(1100~3900 문화예술, 4100~4600 관광, 5100~5500 체육, 7100·7200 문화·관광 일반) + 미래대응기금 편성. 대분류는 캠페인 분류입니다.

## 확인할 것
- 설명자료 총괄표의 2027년 정부안액이 목록 금액과 다른 사업 2건(국립한글박물관 인건비 3,749 vs 목록 3,618, 예술원사무국 인건비 1,072 vs 1,073)은 목록 금액을 씁니다.
- 원문에 소수점이 있는 값(예: 3,582.1)은 백만원 정수로 반올림했습니다.
- 기금 사업 몇 개는 열린재정 설명자료의 「2026년 당초계획액」이 국회 문화체육관광위원회 검토보고서의 2026년 계획과 다릅니다. 관광산업 융자지원(융자) 844,491 vs 644,066, 국민여행 활성화 71,635 vs 52,175, 스포츠강좌이용권 지원 118,422 vs 112,212, 관광산업 인재발굴 및 전문역량 강화 15,134 vs 14,284. 설명자료 안에서는 총괄표와 내역사업 표가 서로 맞아 원인을 알 수 없습니다. 지금은 열린재정 값을 씁니다.
- 대국민 소통 활성화지원은 설명자료 총괄표의 2026년 본예산(7,404)이 2025년 결산과 같고, 내역사업 표의 2026년 예산액(추경)은 13,930입니다. 원문 오기일 수 있습니다. 지금은 총괄표 값을 씁니다.
