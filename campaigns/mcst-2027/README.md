# mcst-2027 — 문화체육관광부 2027년 예산 정부안

budget.codefor.kr(citizen-budget-remix) 저장소의 `campaigns/` 형식에 맞춘 캠페인 데이터입니다.

- `budget.json`: 화면이 읽는 데이터. 대분류 5개, 분야(프로그램) 36개, 세부사업 411개. 단위 백만원.
- `descriptions.json`: 출처·대분류·분야 설명(사람이 고치는 파일). 분야 설명은 세부사업 이름으로 만든 초안입니다.
- `excluded.json`: 뺀 내부거래·보전지출 20건(회계·기금 간 전출, 여유자금 예치).

## 기준
- 원자료: 문체부 사업설명자료(Ⅱ-1) 1~5권, 2026. 9. 정부안.
- 2025 = 결산, 2026 = 본예산(기금은 당초 계획), 2027 = 정부안(총괄표 조정안).
- 분야 = 문체부 프로그램. 대분류 = 프로그램 코드 범위(1100~3900 문화예술, 4100~4600 관광, 5100~5500 체육, 7100·7200 문화·관광 일반) + 미래대응기금 편성. 대분류는 캠페인 분류입니다.
- 세부사업 항목의 `detail`은 비워 두고 단위사업 이름은 `unit`에 넣었습니다(화면은 `detail`을 사업명보다 먼저 씁니다).

## 확인할 것
- 2027 합계 9조 6,681억 원은 문체부 발표 9조 6,345억 원과 약 336억 원 차이가 납니다. 원인은 확인하지 못했습니다.
- 3개 사업(근린생활형 소규모체육관 건립지원, 기초생활체육 저변확산 지원, 국립지방박물관 운영)은 총괄표가 없어 내역 합계표에서 옮겼고, 2025 값은 집행액입니다.
- 문체부 프로그램이 아닌 회계 간 전출 3건이 분야 안에 남아 있습니다: 「문화예술진흥기금 전출」(p1600, 300억), 「지역신문발전기금 전출」(p1400, 112억), 「보세판매장 특허수수료 제주관광진흥기금 전출」(p4200, 3억). 받는 기금의 사업과 겹쳐 셀 수 있습니다. 위 336억 차이와 관련이 있는지는 확인하지 못했습니다.
- 사업명 두 곳(「박물관·미술관 진흥지원」, 「스포츠·공연 복합형 돔구장 건립」)의 가운뎃점이 변환 중 깨져 있어 저장소에 넣을 때 「·」로 고쳤습니다.

## 사이트
